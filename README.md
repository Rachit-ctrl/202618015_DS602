## 📌 Project Overview
This project is an end-to-end data science web application built with Streamlit. It transitions static statistical analysis into an interactive dashboard, allowing users to explore medical insurance costs, run live hypothesis tests, and generate real-time predictions using an Ordinary Least Squares (OLS) regression model.
